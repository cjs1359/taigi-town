# 台語小庄頭 Tiny Taigi Town

學生自己鋪路、劃區、起建築的台語教學小鎮建造遊戲。風格與詞彙對齊[讀冊人台語生活島](https://taigi-life-islands.cjs-1359.chatgpt.site/)，玩法靈感來自《小鎮慢慢長》（僅參考，未使用其程式碼或美術）。

## 線上玩

https://cjs1359.github.io/taigi-town/

建議使用平板或電腦開啟。

## 本機開發

```bash
npm install
npm test
npm run dev
```

建置：`npm run build`（產出 `dist/`，base path `/taigi-town/`）

## 功能（v1.1）

- 2.5D 斜角地圖：鋪路、厝／店頭／工場、多種設施
- 可愛建築美術：平房／透天／公寓、亭仔腳店面、鋸齒工場、燕尾廟、摩天輪等；同類型依格子座標變化
- 場景裝飾：樹、花、山丘、溪水波紋、路緣、小車／人影、飄雲
- 建築 1→3 級成長、收稅、暫停／加速
- 台語詞卡（漢字＋臺羅＋華語）＋教育部辭典發音連結
- 20 張任務卡（三種難度顯示）
- 小島活動一開始全開；蓋好對應建築加分並出現捷徑
- 教師模式：研習中心（進修群島連結）
- 3 個本機存檔欄＋匯出／匯入存檔代碼
- 輕量音效＋靜音
